---
title: Install the app
description: Get the Relay Everything app on an Android phone or an iPhone.
---

The Relay Everything app runs on Android and on iPhone. Each release is built from [the app's code](https://github.com/matthewwong525/RelayEverything/tree/main/mobile) and tested before it goes out.

## Android

1. On the phone, open [the newest release](https://github.com/matthewwong525/RelayEverything/releases/latest).
2. Download the `.apk` file.
3. Open the file. Android asks once to allow installs from your browser: allow it.
4. Tap **Install**.

To update, install the `.apk` of a newer release the same way. Your notes and key stay on the phone.

:::caution
If Android says the app is not installed because it conflicts with the app on the phone, that app is from an older file with a different signature. Do this one time: in the old app, send your notes, then remove the app, then install the new file. Notes that are only on the phone go with the app that you remove.
:::

Test builds that are newer than the release are on [the releases page](https://github.com/matthewwong525/RelayEverything/releases), marked **Pre-release**.

## iPhone

Until the first App Store release, the iPhone app comes through [TestFlight](https://apps.apple.com/app/testflight/id899247664), Apple's app for test builds. TestFlight gets each new build of the app.

1. Install TestFlight from the App Store.
2. Open the invite link that the owner of the Relay Everything server sends you.
3. Tap **Install**.
