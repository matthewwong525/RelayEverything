---
title: Install the app
description: Get the Relay Everything app on an Android phone or an iPhone.
---

The Relay Everything app runs on Android and on iPhone. Each new version is built from [the app's code](https://github.com/matthewwong525/RelayEverything/tree/main/mobile) when it changes.

## Android

1. On the phone, open [the newest release](https://github.com/matthewwong525/RelayEverything/releases/latest).
2. Download the `.apk` file.
3. Open the file. Android asks once to allow installs from your browser: allow it.
4. Tap **Install**.

To update, install the newer `.apk` the same way. Your notes and key stay on the phone.

## iPhone

The iPhone app comes through [TestFlight](https://apps.apple.com/app/testflight/id899247664), Apple's app for test builds.

1. Install TestFlight from the App Store.
2. Open the invite link that the owner of the Relay Everything server sends you.
3. Tap **Install**.

:::note
The iPhone build is not in TestFlight yet. Until it is, you can build the app yourself: [Build it yourself](https://github.com/matthewwong525/RelayEverything/tree/main/mobile#build-it-yourself) gives the steps.
:::
